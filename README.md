# MarketPro (أندرويد) - المرحلة 0

## البناء على GitHub (بدون تثبيت شيء على جهازك)
1. أنشئ مستودعاً جديداً على GitHub، وارفع محتويات هذا المجلد إليه.
2. من تبويب Actions شغّل "Build APK" أو انتظر الدفع الأول إلى main.
3. عند انتهاء البناء، نزّل الملف `MarketPro-debug-apk` من قسم Artifacts، وفيه `app-debug.apk`.

## البناء على جهازك
افتح المجلد في Android Studio، واختر Build > Build APK(s).

## ما الموجود في المرحلة 0
- هيكل المشروع وإعداد Compose.
- شاشة دخول بالعربية (من اليمين إلى اليسار) بعنوان الكمبيوتر وكلمة المرور.
- الاتصال بالكمبيوتر وجلب البيانات يُضافان في المرحلة الأولى.
